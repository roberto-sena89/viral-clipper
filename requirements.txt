numpy>=1.26

# --- Instagram needs TLS impersonation --------------------------------------
# Instagram rejects requests whose TLS fingerprint is not a real browser's, and
# answers with a bare "HTTP Error 400: Bad Request" that names nothing useful.
# With curl_cffi installed, yt-dlp can impersonate Chrome and the same request
# succeeds. Without it, every Instagram URL fails, cookies or not.
#
# The profile listing (`ig_profile.py`) hits the same wall on /api/graphql: the
# request body can be exactly what the browser sends and the answer is still
# `{"__ar":1,"error":1357054}`. There the package is not optional in practice —
# with a session and no curl_cffi, --profile cannot list anything.
#
#   pip install "curl_cffi>=0.7"

# External binaries (must be available on PATH):
#   ffmpeg / ffprobe  - decoding, cutting, rendering, loudness normalization
# They are not Python packages; install them separately.

# --- optional: face-guided reframing (--layout focus) -----------------------
# Without one of these, --layout focus silently falls back to a plain center
# crop. The 4.x line matters: OpenCV 5 removed CascadeClassifier and stopped
# shipping the Haar XMLs, leaving only FaceDetectorYN, which needs an ONNX
# model downloaded at runtime.
#
#   pip install "opencv-python-headless<5"
#
# --- optional: semantic ranker (--ranker llm) -------------------------------
# Nothing to install: it speaks plain HTTP to any OpenAI-compatible
