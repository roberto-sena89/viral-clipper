      Ajustes do projeto

      Estes valores ficam salvos em ajustes.toml, no projeto — valem para toda execução, no painel e na linha de comando, e não dependem do navegador. Sem o servidor no ar, a página abre com os padrões e avisa onde; nada disso é gravado até você clicar em Salvar ajustes.

      A URL do vídeo, a pasta de saída e a quantidade de clips ficam na página Estúdio — mudam a cada trabalho, então não teriam o que fazer aqui.

      Seleção

      Quanto tempo cada corte tem, e quando ele vale a pena.

      0 desliga o portão.
      Com a quantidade em branco, entra todo trecho a até esta distância do melhor do vídeo. Menor = mais exigente.
      Trava dura: mesmo num vídeo muito bom, não passa disto.
      Um trecho que vale a pena pode estourar o máximo acima e terminar a frase. 0 proíbe qualquer estouro.

      Transcrição

      De onde vem o texto que entra no corte — o Whisper ou um texto pronto.

      Persiste entre execuções. Deixa vazio para o padrão.
      Filtro VAD (remover não-fala)
      Cache de transcrição

      Ou cole uma transcrição pronta

      Em branco = o próprio site transcreve com Whisper, com os ajustes acima. Só cole aqui se você já tem o texto pronto — ele substitui a transcrição automática.

      Amarramos texto e vídeo para o texto não vazar para outro vídeo. Trocar a URL na aba Estúdio faz este texto ser ignorado até você o colar de novo.
      Aceita SRT, WebVTT, o painel de legendas do YouTube (0:05) ou texto puro.
      Ao colar, o texto é organizado sozinho: minutos em ordem, falas alinhadas à esquerda.

      Renderização

      Como o corte sai: enquadramento, legendas, título no topo e áudio.

      Define fonte, cor, caixa e destaque de uma vez. Campos vazios abaixo herdam do preset.
      Vazio = usa o tamanho do modelo de legenda.
      Menor = melhor qualidade.
      O painel mandava lufs e o motor espera target_lufs: até agora este campo não chegava ao vídeo.
      Reduza se faltar RAM.
      Só se aplica com o título ligado acima.
      Título do gancho no topo (desligado = só legendas)
      Barra de progresso no topo (desligada = vídeo limpo)
      Jump cut (remover silêncios internos)
      Normalizar loudness

      Prompt do curador

      As regras em prosa que escolhem os melhores trechos do vídeo.

      Escreva em prosa livre, do jeito que você escreveria para uma pessoa. O formato de resposta (o JSON com as notas, a headline e as hashtags) é anexado pelo próprio motor — não precisa escrevê-lo, e ele não se perde quando você edita o texto.

      Versionado no git: dá para ver o que mudou entre versões e voltar atrás se os cortes piorarem. Editar o arquivo invalida o cache do curador automaticamente.
