Configuração do corte

Todos os parâmetros do python -m viralclipper mapeados. Flags da interface vencem o --config.

▶ Fonte

O único campo obrigatório: cole e clique em Gerar clips para ir com os padrões.
Local ou sincronizada (Drive, OneDrive, Dropbox): abre o seletor do computador. Relativa = a partir de onde o servidor roda.
Acessar vídeo restrito (opcional) Só para vídeos com restrição de idade. A maioria dos vídeos públicos passa sem isto. No Chrome/Edge 127+ o seletor sempre falha (App-Bound Encryption) — nesse caso use o arquivo abaixo. Tem precedência sobre o seletor acima. Exporte com uma extensão do navegador.

≡ Transcrição (só se já tiver uma)

Em branco = o próprio site transcreve com Whisper. Só cole aqui se você já tem o texto pronto — ela substitui a transcrição automática.

Aceita SRT, WebVTT, o painel de legendas do YouTube (0:05) ou texto puro.
Ao colar, o texto é organizado sozinho: minutos em ordem, falas alinhadas à esquerda.

▣ Renderização

Define fonte, cor, caixa e destaque de uma vez. Campos vazios abaixo herdam do preset.
Vazio = usa o tamanho do modelo de legenda.
Menor = melhor qualidade.
Reduza se faltar RAM.
